Chat should exist, but it must be controlled.

The system should allow:

Admin-to-owner chat
Admin-to-finder chat
Owner-to-intermediary chat
Finder-to-intermediary chat

The system should not allow:

Owner-to-finder direct chat
Private negotiation
Unsafe contact sharing
Harassment
Threats
Uncontrolled communication

Admin should be able to initiate, monitor, pause, or terminate chat when necessary.

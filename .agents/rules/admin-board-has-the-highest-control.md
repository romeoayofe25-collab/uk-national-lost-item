The Admin Board is the main authority in the system.

Admin should be responsible for:

Setting rewards
Managing disputes
Reviewing suspicious activity
Approving or rejecting claims
Verifying owners and finders
Monitoring item recovery processes
Initiating and terminating chats
Managing intermediary/drop-off centres
Handling reports of fraud, abuse, or criminal activity

Any feature involving risk, payment, verification, or communication must include admin control.
